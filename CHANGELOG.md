# Changelog

All notable changes to nxtconvert. Each version's notes are also shown in the app's update panel.

## 0.1.5

- Convert CAD drawings: DXF to SVG, PDF, PNG, JPG and other image formats, and SVG to DXF for laser cutters, CNC and CAD software. Drawings keep their real size, layer colours and text; circles stay true circles.
- SVG and DXF to PDF now produce a vector PDF at the drawing's real size instead of an image.
- Fixed: after converting, the Convert button stayed disabled. It now offers "Convert again", and changing the Save to folder marks finished files as ready.

## 0.1.4

- macOS: nxtconvert is now signed and notarized by Apple. It opens without warnings, and fixes the "nxtconvert is damaged" message when opening earlier downloads.
- macOS: updates now install from inside the app.

## 0.1.2

- Choose the output size when converting SVG to PNG, JPG and other image formats: Settings → Images → Vector size (original, 2×, 3×, 4×, or a fixed width up to 4096 px). Drawings are re-rendered at that size, so edges stay sharp.

## 0.1.1

- HEIC photos convert to JPG about three times faster on Windows and Linux, and batches of photos now convert two at a time.
- Converting to JPG is much faster on every system.
- The app stays responsive while HEIC photos convert.

## 0.1.0

- First release: images, video, audio and documents, converted on this computer.
- Checks for updates when it opens and offers to install them.
